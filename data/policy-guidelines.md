# WWF Presentation Policy Guidelines

## Overview
This document outlines the policy guidelines for creating WWF-style presentations using the mock presentation generator system.

## Content Standards

### Accuracy
- All factual claims must be verifiable and sourced
- Statistics should be from reputable sources (WWF reports, UN data, etc.)
- Avoid speculation or unverified claims

### Tone and Language
- Use clear, accessible language
- Maintain a professional yet engaging tone
- Avoid jargon unless clearly defined
- Use active voice where possible

### Visual Guidelines
- Follow brand color palette strictly
- Ensure sufficient contrast for readability
- Use high-quality images only
- Include proper photo credits for all images

## Compliance Requirements

### Brand Compliance
- WWF logo must be used according to brand guidelines
- Minimum clear space around logo: 20px
- Logo must not be altered or distorted
- Approved color variations only

### Partner Attribution
- Partner logos must be displayed according to partnership level
- Platinum partners: prominent placement
- Gold partners: secondary placement
- Silver/Bronze partners: group placement

### Legal Requirements
- All images must have proper licensing
- Photo credits must be included on each slide using images
- Partner logos require written permission for use
- Copyright notices must be visible

## Slide Structure

### Required Slides (5-slide format)
1. **Title Slide**: Presentation title, subtitle, date, presenter
2. **Overview/Introduction**: Key message and objectives
3. **Main Content**: Core information with supporting visuals
4. **Impact/Results**: Data, achievements, or call to action
5. **Partners & Credits**: Partner logos and photo credits

### Optional Elements
- Section dividers (for longer presentations)
- Data visualizations (charts, graphs)
- Quote slides (for emphasis)
- Q&A slide

## Validation Checklist

Before finalizing any presentation, ensure:
- [ ] All brand guidelines are followed
- [ ] All images have proper credits
- [ ] Partner logos are correctly attributed
- [ ] Content is accurate and sourced
- [ ] Spelling and grammar are correct
- [ ] Slide count matches requirements
- [ ] File is saved in correct format (PPTX)
